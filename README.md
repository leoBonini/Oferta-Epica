# Oferta Épica

Aplicativo React + Vite para auditar ofertas com 21 pilares. Briefing com 17 perguntas, autosave local, exportação/importação JSON e comando de IA sem API paga.

## Executar

```bash
npm install
npm run dev
```

## Publicar

Vercel: framework Vite, build `npm run build`, diretório `dist`.

Os dados dos alunos ficam no localStorage do navegador. O aplicativo não chama serviços de IA.
